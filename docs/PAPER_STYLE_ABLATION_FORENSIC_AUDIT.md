## Stage A: state and RNG inventory

`train_writer_variant` creates `make_model(...)` inside each invocation (`experiments/run_paper_style_ablation.py:143-145`), and `BTSPCAM.__init__` allocates new encoder, trace, zero memory, ridge, plateau generator, and synapse generator (`src/btsp_cam/model.py:47-99`). Its writer loop uses cached codes but does not mutate them: `ClassEligibilityTraces.update` converts each code to float64, `BinaryMemory.update` reads active indices, and saved W_B is packed into an independent array (`src/btsp_cam/eligibility.py:50-59`; `src/btsp_cam/binary_memory.py:39-69`; `experiments/run_paper_style_ablation.py:122-160`). A3's advanced-index `before` is copied before mutation (`:96-107`). The branch-specific ridge is newly created within `fit_task` (`:238-249`); no ridge object is shared.

RNG provenance is `RNGProvenance.from_seed(1993)` with separate train-order, augmentation, projection, plateau, and synapse seeds (`src/btsp_cam/rng.py:21-34`; `experiments/run_k_robustness_and_selection.py:58-67`). This runner uses precomputed sparse codes: the original Python/NumPy/torch CPU/CUDA shuffle/augmentation generators are not consumed during the ablation writer/readout pass. Plateau draws consume 4096 uniforms on every sample in all branches (`src/btsp_cam/plateau.py:33-38`). Synapse draws consume `#plateaus × 96` uniforms only when plateaus occur (`src/btsp_cam/binary_memory.py:56-69`), so A1/A2 diverge from Full in later synapse RNG state even with paired initial seeds. This is **event-level RNG non-pairing**, not by itself branch-state leakage. A3 consumes the same synapse draw count as Full so long as plateau events remain equal. Partial-cue generators are local `default_rng(seed+task)` instances (`experiments/run_paper_style_ablation.py:401-411`); the five seeds are distinct for a fixed task, but adjacent `(seed, task)` pairs can yield an identical integer seed across different tasks. This limits a strict claim of independent aggregate-seed replicates and must be interpreted in the denominator crosscheck.

## Stage B: independent numeric checks

The independent read-only checker `tmp/audit_recompute_ablation.py:37-186` does not import the ablation runner or its summary code. It unpacked cached exact-96 codes/labels and all four saved W_B trajectories, built the CA1/ridge features directly, and checked Tasks 1, 5, 10, 20 for Full/A1/A2/A3. Every cumulative, old, current, restricted-current accuracy, source-task accuracy and W_B density matched the original CSV: maximum accuracy discrepancy **2.22e-16**, density discrepancy **0**. Classification: **EXECUTION_CORRECT**, not `RESULT_AGGREGATION_BUG`. The independent 120-row metric arithmetic check found zero discrepancy for cumulative, old, current, running Abar and local Fgt; Full versus the 20-row frozen confirmation differed by at most 1.11e-16. `Abar` is exactly the arithmetic mean of 20 cumulative top-1 accuracies, not a weighted mean.

For A2, the actual writer function was exercised on 1000 Task1 cached training samples. Its `I_effective` was exactly 1.0 and its probability equaled `.005 × 4N(1−N)F` with maximum absolute error **0**. The independent Full probability calculation also had error 0 (`tmp/audit_ablation_branch_order.py:67-77`; `tmp/audit_recompute_ablation.py:100-132`). A3's 16-case old-bit/plateau/active-bit/Bernoulli-hit truth table passed using `BinaryMemory.update` plus the A3 post-update operation (`tmp/audit_ablation_branch_order.py:25-48`). Its saved 1→0 count is 0 for every task; its plateau counts equal Full task by task (`experiments/run_paper_style_ablation.py:92-114`; `diagnostics/paper_style_ablation_mechanisms.csv`). The same Task1 first-50-sample codes run in forward and reverse branch order yielded identical per-branch memory/trace/log hashes: **BRANCH_ORDER_INDEPENDENT_PASS** (`tmp/audit_ablation_branch_order.py:51-78`). This is a targeted order test, not a claim that different ablation paths are eventwise RNG-paired.

## Readout × ablation crosscheck

`diagnostics/readout_ablation_crosscheck.csv` contains all 20 taskwise evaluations per writer variant. `tmp/audit_recompute_ablation.py:188-219` used each variant's saved `WB_taskXX`, added **only that task's** train `Z_tᵀZ_t` and `Z_tᵀY_t` to persistent A/B, expanded class columns, solved the unchanged gamma=.1 ridge, and evaluated all seen *test* sparse codes. Historical training codes were not read for the streaming update. This is a literal Eq.(8) interpretation diagnostic, not proof of author-code behavior.

| Variant | Replay-refit Abar / Final | Streaming A/B Abar / Final | ΔAbar replay vs Full | ΔAbar streaming vs Full |
|---|---:|---:|---:|---:|
| Full | 85.553 / 79.180 | 31.934 / 20.630 | — | — |
| A1 fixed gate | 84.855 / 79.000 | 26.167 / 11.350 | −0.698 pp | **−5.767 pp** |
| A2 I:=1 | 85.397 / 79.590 | 30.488 / 18.300 | −0.156 pp | **−1.446 pp** |
| A3 only LTP | 85.475 / 79.220 | 35.712 / 30.070 | −0.078 pp | **+3.778 pp** |

Classification: **READOUT_CONFOUND**. On this saved geometry, replay-refit markedly attenuates A1/A2 accuracy deficits and changes A3's sign. Full itself loses **53.619 pp Abar** (85.553→31.934) and **58.55 pp Final** (79.18→20.63) under literal old-A/B accumulation. The enlarged streaming A1/A2 deltas must not be cited as paper-like mechanism validation in isolation, because the Full reference already suffers severe temporal feature-coordinate mismatch. A3's positive streaming delta further prevents a single “replay masks all ablations” explanation. Eq.(8) in the PDF says A/B use only current-task data and keep old sufficient statistics (printed p.6 §4.5); it does not specify historical current-W_B replay. The local replay readout is an experimental repair and is not author-equivalent.

## Partial-cue denominator and RNG audit

The original mask uses `round(96r)` active bits: for r=0/.3/.6/.8 this is 0/29/58/77, leaving 96/67/38/19; active-bit-only deletion and per-sample masks were independently asserted (`tmp/audit_recompute_ablation.py:222-247`). Drop0 exactly matches Task20 old-class accuracy for all four original variants (`experiments/run_paper_style_ablation.py:426-432`; `diagnostics/partial_cue_robustness.csv`). No corrupted cue appears in writer/ridge training. `diagnostics/partial_cue_normalization_crosscheck.csv` compares the original *remaining-bit* denominator against fixed original k=96 with the same masks and saved readouts. Values below are five-seed mean old-class accuracy (%):

| Variant | Drop ratio | Remaining-count denom. | Original-k denom. | Original minus remaining |
|---|---:|---:|---:|---:|
| Full | .3 | 76.691 | 76.686 | −0.004 pp |
| Full | .6 | 69.844 | 69.834 | −0.011 pp |
| Full | .8 | 56.434 | 53.661 | **−2.773 pp** |
| A3 only LTP | .8 | 56.017 | 55.817 | −0.200 pp |
| A4a no threshold | .8 | 56.457 | 56.457 | 0 pp |

At 80% drop, the Full−A3 gap reverses from +0.417 pp (remaining denominator) to −2.156 pp (fixed k); therefore the denominator **is confounding** for the local robustness separation. For A4a, denominator is a positive common scaling of all feature components for a fixed ratio, so argmax is invariant. Paper Eq.(7)/Appendix F.1 Eqs.(31)-(32) mathematically favor remaining `||s'||_1`, but Table 5 gives no operational statement for the corruption experiment. Classification: **PAPER_OPERATION_UNSPECIFIED** for Table 5 procedure and **METRIC_OPERATIONALIZATION_MISMATCH** if either denominator is assumed paper-exact.

The original `default_rng(seed+task)` at `experiments/run_paper_style_ablation.py:405` (pre-correction) mapped 5×19=95 seed/task pairs to only **23 unique integer seeds**. For identically shaped 500×96 mask draws, distinct cross-task/replicate pairs reused an identical random index pattern. This is a **noncritical IMPLEMENTATION_BUG** in the claimed five independent aggregate partial-cue repetitions, not a writer/branch `RNG_STATE_LEAK_BUG`. Stage B changed only this experimental mask RNG to `SeedSequence([seed,task])`, leaving the old CSV untouched and writing `diagnostics/partial_cue_robustness_corrected.csv` (`experiments/run_paper_style_ablation.py:388-433`; `tests/test_paper_style_ablation.py:63-70`). The 95 derived test streams produced 95 distinct 64-bit fingerprints. Corrected Full means at drops .3/.6/.8 are **76.592/69.754/56.446%**, versus original **76.691/69.844/56.434%**; the maximum among those shifts is 0.099 pp. Thus the RNG error affects independence/uncertainty, but does not explain the near-overlapping ablation curves. No writer, W_B, ridge or formal config was retrained/changed.

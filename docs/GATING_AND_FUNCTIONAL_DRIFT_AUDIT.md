# Eq.(5) 门控、真实 XOR 与旧 overlap 漂移（Task1–5）

本轮只做诊断。读取正式缓存、seed=1993 原配置、固定 `R,b` 与 Task1–5 checkpoint；没有修改正式模型/参数、没有重新训练 `W_B`，也没有产生新的随机轨迹。B 部分在内存中按原 seed 和调用顺序重放 plateau/flip，五个任务末 `W_B` 均与正式 checkpoint **逐 bit 相同**。论文机制参照 [BTSP-CAM 原文](../../2233_BTSP_CAM_A_Brain_Inspired.pdf)第 5 页 Eq.(5)–(6) 和第 17 页 Appendix F.2。所有数值为当前 reproduction 的 Task1–5 诊断，不反推作者未公开实现或最优参数。

## B（最高优先级）：逐事件 XOR 到 Task1 旧 `a` 的代数闭合

固定 probe 是 **Task1 全部 500 个测试样本**的正式 sparse code，`k=41`；基准 `a_1=W_B^{(1)}s/41`，终点 `a_5=W_B^{(5)}s/41`。Task1 train probe 未增加，避免重复计算已由 test 全量提供的逐元素闭合。对 Task2–5 的**每次真实 flip**记录任务、训练样本碰撞四分位、当时的历史频率 bit 组、方向、slot `j` 与 column `i`；该事件对任一固定旧 query `q` 的贡献严格是 `±s_q[i]/41`。事件按组先在整数 `ΔW` 中求和，再乘旧 query 矩阵；整数计数避免浮点累加误差。

四个新 task 共 **1,267,909** 次真实 flip（0→1：**1,083,013**；1→0：**184,896**）。每个 task 的事件矩阵精确等于其前后 checkpoint 差值。对 500×4096 个旧 `a` 元素，`Σ_event Δa = (W_B^{(5)}−W_B^{(1)})S_1/41` **逐元素成立，最大绝对误差 0**；按 task、方向、碰撞四分位或 bit 组各自相加也精确闭合。这证明的是**实际轨迹的代数贡献**，不是移除某事件后的训练反事实。[逐组事件贡献](../diagnostics/flip_to_feature_drift_by_task.csv)、[逐 task×bit 记录](../diagnostics/flip_to_drift_by_bit_hotness.csv)。

“gross functional movement”定义为各 flip 对所有 Task1 probe 被触及的 `|1/41|` 元素数之和，即 `Σ_event query_fanout(i)/41`；它在事件间**不抵消**。net 指事件加总后的 `Δa`。所有事件 gross L1 为 **315,731.37**，终态 net L1 为 **164,726.68**（gross/net≈**1.92**）。净 `Δa` 的 signed mean 为 **+0.078876**、mean absolute 为 **0.080433**、Frobenius L2 为 **138.309**。所以只看 checkpoint 净变化会漏掉大约一半被相反事件抵消的功能移动。

| 方向 | flip 数 | gross functional L1 | 净 signed mean `Δa` | event-only L2 | 相对 `a1` 的正交 L2 |
|---|---:|---:|---:|---:|---:|
| 0→1 | 1,083,013 | 238,634.80（75.6%） | +0.116521 | 194.02 | 147.05 |
| 1→0 | 184,896 | 77,096.56（24.4%） | −0.037645 | 76.87 | 55.00 |

**0→1 是旧 `a` 净增大与正交漂移的主贡献；1→0 部分抵消它**。虽然 1→0 仅占 flip 数 14.6%，却占 gross functional movement 24.4%，因为其被翻转的 column 对旧 query 有较大 fanout。单组 `a1+Δ_group` 的 cosine 在 CSV 中只是向量诊断：单独取出 LTD 组可产生非物理的负“权重”，不能解释为可运行的 `W_B` 状态。

按写入 task，Task2/3/4/5 的 gross functional L1 分别为 **82,880 / 77,898 / 73,526 / 81,427**；对应正交 L2 为 **55.30 / 49.53 / 46.00 / 46.70**。各 task 均造成实质变化，没有单一末任务独占漂移。

## B：高碰撞样本与热点 bit 的放大

碰撞 Q1–Q4 完全沿用前轮规则：**各 Task2–5 内**按与历史码的 mean collision 稳定排序，各分 625 样本，再合并同名四分位，因此每组恰为 2,500 张、占新样本的 25%。

| 训练样本组 | flip 数占比 | gross functional L1 占比 | event-only 正交 L2 | 对最终正交残差的 signed dot share |
|---|---:|---:|---:|---:|
| Q1 | 24.1% | 17.9% | 43.03 | 20.3% |
| Q2 | 24.5% | 22.8% | 48.32 | 23.8% |
| Q3 | 25.9% | 27.6% | 52.57 | 26.9% |
| Q4 | 25.6% | **31.7%** | **55.10** | **29.0%** |

Q4 确有功能漂移富集：同为 25% 样本，gross 贡献 **31.7%（1.27× 样本占比）**，正交残差 signed dot share **29.0%（1.16×）**，正交 L2 为 Q1 的 **1.28×**。它是**中等而非压倒性的**不成比例贡献，不能写成“Q4 单独造成大多数 drift”。与前轮已验证的 `old_code_collision → 旧 imprint 暴露 → 1→0` 关联连起来，当前事件归因又证明这些样本的真实 flip 对旧 `a` 有更大代数作用；但没有独立改变碰撞而保持其余轨迹不变的干预。

bit 热度以**每个新 task 开始前历史训练码**的 column 激活频率定义，按 8192 bit 的稳定排名分为互斥的 `top 1%`（82 位）、`next 1–5%`（328 位）、`middle 5–50%`（3686 位）、`bottom 50%`（4096 位）。因此同一个 bit 在不同新 task 可落到不同组。`query_fanout(i)` 是 500 个固定 Task1 测试码中包含 bit `i` 的 query 数，完全决定单次该 column flip 能影响多少旧 query。

| 历史热度组 | bit 数份额 | flip 数份额 | gross functional L1 份额 | 最终正交残差 signed dot share |
|---|---:|---:|---:|---:|
| Top 1% | 1.0% | 17.4% | **42.5%** | 27.4% |
| Next 1–5% | 4.0% | 28.2% | **35.6%** | 40.8% |
| Middle 5–50% | 45.0% | 50.2% | 21.7% | 31.4% |
| Bottom 50% | 50.0% | 4.2% | 0.3% | 0.4% |

Top 5% 合计贡献 **78.0% 的 gross functional movement**、**68.2% 的最终正交残差 signed dot share**，远高于 5% 的位数份额。逐 task、逐 bit 诊断表给出历史频率、Task1 query fanout、0→1/1→0 次数、gross 功能影响和净 column 影响。各 Task2–5 中，历史 bit 频率与后续该 bit flip 数的 Pearson 为 **0.801–0.826**；历史频率与旧 query fanout 为 **0.460–0.583**。热点被反复写入，且旧 query 更可能使用它，两者相乘造成大的功能 fanout。这是实际 `sparse hotspot → collision/reuse → plateau 暴露 → XOR flip → old a drift` 的**可追溯代数链**；没有证明关闭热点会使 accuracy 提升多少。

## B：与 Appendix F.2 的缩放假设及 margin

令所有 500 个 probe 的 `a` 堆叠为矩阵，以单一最小二乘标量拟合 `min_ρ ||a5−ρa1||_F`。得到 **`ρ*=1.644800`**，残差 `ε=a5−ρ*a1` 的 L2 为 **117.562**，占 `||a5||_F` 的 **53.46%**。这针对的是**阈值前 `a`**；Appendix F.2 讨论的是理想化 CA1 `z` 的 `ρ∈(0,1]` 与 sparse noise，二者不能混作直接反例。当前 `a` 不只是单一保留率缩放。

对任一组事件 `g`，CSV 的 `parallel_signed_coefficient = <a1,Δ_g>/||a1||²`，`orthogonal_norm = ||Δ_g−parallel_g·a1||_F`。全体组的正交**向量**可线性相加为最终 `ε`；其平方范数/能量**不能逐组直接相加**，因为组间有交叉项和抵消。为给出可加的带符号残差归因，`residual_dot_share = <orth_g,ε>/||ε||²`，同一完整划分的 share 之和为 1，可负或超过 1。按方向，0→1 的 share 为 **+117.3%**，1→0 为 **−17.3%**，说明 LTD 在本轨迹上净抵消部分最终正交残差；这不是可分的“能量百分比”。

固定 Task1 test 的原始余弦 class margin 从 **0.083839** 降至 **0.019636**（−76.6%）；different-class cosine 从 **0.688792** 升至 **0.867879**，same-class 从 **0.772632** 升至 **0.887515**。为区分公共密度抬升和居中特征改变，令每个 checkpoint 的 500-query 均值为 `μ_t`，离线构造 `μ5+(a1−μ1)`（只换公共均值）及 `μ1+(a5−μ5)`（只换居中特征）。两种顺序平均的 Shapley 式**描述性**拆解，把原始余弦 margin 的 `−0.064204` 变化分为公共均值 **−0.057683（89.8%）**、居中特征 **−0.006521（10.2%）**。因此就**原始余弦 margin 损失**而言更接近 common-mode density increase；但正交残差达 `||a5||` 的 53.5%、既有中心化 margin 也从 0.2996 降至 0.1758，故不能说 class geometry 完全不变。混合向量不一定是物理可达的二值记忆状态，这个拆解不是移除某机制后的因果效果。

## A：为什么 `I` 降而 `f_eff` 不降？

在前轮 10,000 个 Task2–5 逐样本 replay 行上，定义 `G_FN=4N(1−N)F`。数值核对全部通过：`N=1−F` 给出 `G_FN=4F²(1−F)`，且 `f_eff=f_base·G_FN·I`（`f_base=0.005`）。理论上 `G'(F)=4F(2−3F)`：在 `0<F<2/3` 单调增加，在 `2/3<F<1` 减少，最大点 `F=2/3`，`G_max=16/27`。真实 F 的 median **0.3886**、p10/p90 **0.2941/0.4896**，**99.55%** 低于峰值，因此更高的 familiarity `F` 通常会**提高** `G_FN`。

| 按各 task 历史 collision 的合并分位 | F | N | `4N(1−N)` | `G_FN` | I | 真实 `f_eff` | CF-I-only | CF-G-only | plateau/样本 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| Q1 | 0.3645 | 0.6355 | 0.9005 | 0.3331 | 0.8749 | 0.001455 | 0.001606 | 0.001371 | 5.952 |
| Q4 | 0.4183 | 0.5817 | 0.9502 | 0.4002 | 0.7665 | 0.001532 | 0.001407 | 0.001648 | 6.342 |

所有 CF 都**只计算概率，不抽取 plateau、不训练 W_B**。CF-I-only 在每个 task 固定 `G_FN` 为该 task 均值；CF-G-only 固定 `I` 为该 task 均值；CF-no-I 取 `f_base·G_FN`；CF-I-with-fixed-F 用该 task 的 median F 形成固定 G 再乘真实 I。完整字段和 Q1–Q4、各 task 的均值见 [门控分位表](../diagnostics/gating_component_by_collision.csv)。历史碰撞对 `F,N,G_FN,I,G_FN·I,f_eff` 的 Pearson/Spearman（pooled 及各 task）见 [相关性表](../diagnostics/gating_component_correlations.csv)。Pooled Pearson 分别为 **+0.253、−0.253、+0.271、−0.826、+0.073、+0.073**。

Q1→Q4：`I` 减少 **12.4%**，`G_FN` 增加 **20.1%**；固定 G 的 CF-I-only 概率下降 **12.4%**，固定 I 的 CF-G-only 概率上升 **20.2%**，真实 `f_eff` 反而上升 **5.3%**。对组均值的乘积作精确差分 `mean(GI)=mean(G)mean(I)+cov(G,I)`，Q4−Q1 在概率单位内分解为：`G` 变化 **+0.00027528**、`I` 变化 **−0.00019879**、组内 covariance 变化 **+0.00000065**，合计真实 **+0.00007714**。**G 的增强抵消了约 138% 的 I 单独抑制量**（只针对该 Q1/Q4 差分定义）。进一步把 `G=(4N(1−N))×F` 以同样对称差分拆开，F 显式乘子贡献 `ΔG≈+0.04976`，几何 prior 贡献 `+0.01948`，协方差 `−0.00215`；**F 上升是主要项**，而 N 从 0.635 向 0.582（靠近 0.5）也使 `4N(1−N)` 增大。不能将 F 与 N 当作统计独立的两个原因；`N=1−F`。

## C：保度随机化的交换深度

从相同正式 Task1–5 码出发，三条确定性 switch 链（seed 9301–9303）分别在累计接受 `1×、5×、10×、20×` 原 512,500 条 1-edge 时测量。每次交换限制在同一 500 样本 class 内，**逐行 41、逐 class/bit 列总数均精确保留**，最终重新断言。每个 seed 固定抽取 150,000 个跨 task 异类 pair 并在四个深度重复使用；CSV 对每个概率给出固定矩阵条件下的近似 95% pair-sampling CI。[混合核查全表](../diagnostics/degree_randomization_mixing.csv)

| 交换深度 | 三 seed 平均 `P(J≥1)` | `P(J≥2)` | `P(J≥3)` | `P(J≥4)` | `P(J≥5)`；seed 范围 |

| 1× | 0.7941 | 0.4675 | 0.2108 | 0.0751 | 0.02226；0.02181–0.02303 |
| 5× | 0.7953 | 0.4699 | 0.2103 | 0.0748 | 0.02239；0.02203–0.02263 |

5×/10×/20× 的高尾 `P(J≥5)` 无持续漂移，且与前轮独立 5× 对照约 **2.22%–2.29%** 一致；真实精确值 **4.7411%** 仍约高两倍。因此前轮结果**未显示明显的 5× 未混合伪影**。有限链和三个 seed 不是严格的全状态空间 mixing 证明；1× 已接近稳定区间也不意味着每一高维统计都已充分混合。

## 最终判断与边界

1. **A / 为什么 `I` 强降却不压低 `f_eff`：** 高碰撞样本 `F` 增加，而实际 F 绝大多数处于 `G(F)` 的上升段；显式 F 乘子为主，`N=1−F` 靠近 0.5 后几何 prior 同向增强。Q1→Q4 的 G 增强超过 I 抑制，净概率 +5.3%。
2. **C / flip→drift 是否闭合：** 是，Task2–5 每次真实 flip 的 `±1/41` old-query 贡献在整数计数上与两个 checkpoint 直接差值逐元素相同，最大误差 **0**。
3. **D / 方向：** 0→1 主导净增、gross 和正交漂移；1→0 有功能影响但在当前实际轨迹部分抵消最终正交残差。
4. **E / 不成比例贡献：** Q4 为 25% 样本却贡献 31.7% gross、29.0% signed residual share，属于**中等富集**；动态 top 1% 热 bit 贡献 42.5% gross，top 5% 贡献 78.0%，属于**强富集**。
5. **Margin：** 原始余弦 margin 的下降以公共分量抬升为主（描述性拆解 89.8%），同时存在非标量、居中特征变化；不能把 margin 分解当作 accuracy 或模型干预因果分解。
6. **F / mixing：** 5×、10×、20× 的 `P(J≥5)` 稳定在约 2.2%–2.3%，先前保度重尾对照结论保持。没有选择任何参数、没有据此修模型。

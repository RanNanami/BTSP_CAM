# W_B 漂移与 ridge 时间不一致：Task1–5 诊断

本轮仅分析 CIFAR-100 B0-Inc5 的前五个任务。所有 BTSP 读出统一为未阈值化的 `a = W_B s / ||s||_1`，没有使用 tau、修改正式模型、调参数或重新训练 W_B。O1/O2 读取原始 R0 的 `WB_task1`–`WB_task5`；随机对照只在内存中生成固定矩阵。随机对照仍使用原始 sparse codes、相同类别与样本顺序、gamma 和现有 `StreamingRidge`。两份逐行数据见 `diagnostics/current_wb_oracle_ridge.csv` 与 `diagnostics/fixed_memory_controls.csv`。

## 核心答案

| Task5 条件 | 累计准确率 | 旧类准确率 | 当前任务准确率 |
| --- | ---: | ---: | ---: |
| R0：历史 A/B + 演化 W_B | 33.00% | 17.65% | 94.40% |
| O1：固定当前 WB5，全部已见训练样本统一重映射并整批拟合 | **85.52%** | **85.00%** | 87.60% |
| O2：同一 WB5，逐 task 累加 A/B 后拟合 | **85.52%** | **85.00%** | 87.60% |
| R1：Task1 后冻结 WB1 + streaming ridge | 85.92% | 85.75% | 86.60% |

按用户定义的诊断性 gap：

- `TEMPORAL_MISMATCH_GAP = O1(WB5) − R0 = 85.52% − 33.00% = 52.52 个百分点`。
- `MEMORY_GEOMETRY_GAP = R1(WB1) − O1(WB5) = 85.92% − 85.52% = 0.40 个百分点`。

两项数值相加等于 R1−R0 的 52.92 个百分点，但**不是严格因果百分比分摊**。O1 允许完整历史训练数据重放和重新拟合，既重对齐了旧统计量，也让分类器重新利用 WB5 的全部几何；R1 则使用另一条固定记忆轨迹。就本设置的可解码性而言，WB5 本身没有造成接近 52.92 个百分点的不可恢复损失；主要性能崩溃发生在旧 A/B 与当前 W_B 所定义特征空间的时间不一致。

## O1/O2：固定特征空间下的 ridge 核查

每个 task t，O1 把 D1…Dt 的训练 sparse codes 全部经同一个原始 `WB_task_t` 变成 a，一次性更新 ridge；O2 用**完全相同的 a** 按 Task1…Taskt 顺序累加充分统计量，最后求解。所有数据均为原始缓存和正式 R0 sparse codes；没有生成新训练样本。

| Task | R0 累计 | O1/O2 累计 | R1 累计 | O2 与 O1 的权重最大绝对差 | logit 最大绝对差 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 92.40% | 92.40% | 92.40% | 0 | 0 |
| 2 | 51.40% | 89.80% | 90.60% | 1.86e−11 | 6.03e−12 |
| 3 | 36.87% | 87.07% | 88.33% | 3.66e−11 | 9.12e−12 |
| 4 | 33.70% | 85.55% | 86.15% | 5.07e−11 | 1.43e−11 |
| 5 | 33.00% | 85.52% | 85.92% | 6.33e−11 | 2.04e−11 |

O1/O2 的逐样本预测在全部五个 checkpoint 上完全相同。因此固定 W_B 时，一次性拟合和 Eq.(8) 式逐 task 累加的实现等价；本轮没有发现 ridge 累加或求解器错误。Task5 重建的 R0 读出也精确复现 33.00%，提供了独立基线核查。

WB5 下各 source task 测试准确率如下。每个 source task 有 500 张测试图，预测均在已见 25 类中进行。

| 测试来源 | R0 历史 A/B + WB5 | O1 统一 WB5 重拟合 | 恢复 |
| --- | ---: | ---: | ---: |
| Task1 | 3.20% | 91.60% | +88.40 pp |
| Task2 | 2.00% | 83.60% | +81.60 pp |
| Task3 | 8.60% | 83.20% | +74.60 pp |
| Task4 | 56.80% | 81.60% | +24.80 pp |
| Task5 | 94.40% | 87.60% | −6.80 pp |

旧任务均能在 WB5 的同一特征空间内大量恢复，尤以前三任务明显。Oracle 对新任务的 25 类准确率反而低于 R0，说明 R0 的高新类成绩与严重旧类损失共同出现，不能只看当前任务评分判断记忆质量。

## WB1 固定映射对照

`TRAINED_WB1` 为正式原始 checkpoint，整段 Task1–5 不再写入 W_B。`RANDOM_DENSITY_MATCHED` 用 WB1 的全局占用率 **0.91573%** 作为 Bernoulli 参数，三个预先固定的种子为 199301–199303；实际密度分别约为 0.91421%、0.91551%、0.91661%。`DEGREE_MATCHED_RANDOM` 用种子 199304–199306 对 WB1 做二部图双边交换，每份接受恰好 **5×原始边数** 的交换，即 1,536,340 次；每行和每列的度数在交换后逐项与 WB1 完全相同。三组随机矩阵都在 Task1–5 永久冻结，按任务流式更新同一 ridge；没有根据成绩选择种子。

| 固定 W_B 类型 | Task5 累计准确率 | Task5 当前任务 5-way | Task5 当前任务 a 余弦 margin |
| --- | ---: | ---: | ---: |
| TRAINED_WB1 | **85.92%** | **95.60%** | 0.03767 |
| Bernoulli 密度匹配：199301 | 84.80% | 95.60% | 0.05069 |
| Bernoulli 密度匹配：199302 | 84.44% | 95.00% | 0.05241 |
| Bernoulli 密度匹配：199303 | 84.44% | 94.20% | 0.05131 |
| 严格保度：199304 | 85.24% | 95.60% | 0.03032 |
| 严格保度：199305 | 85.36% | 95.20% | 0.02976 |
| 严格保度：199306 | 85.12% | 95.40% | 0.02962 |

密度匹配组 Task5 累计均值 **84.56%**（范围 84.44%–84.80%）；保度组均值 **85.24%**（范围 85.12%–85.36%）。Trained WB1 高出这两个均值 **1.36 pp** 与 **0.68 pp**，不是数量级上的优势。前三种方法的不同 a 分布/基线余弦使单一 cosine margin 不宜跨矩阵当作准确率因果解释；CSV 还保留了 same/diff、全已见类 Task5 几何和所有 task 的 5-way 指标。

## 对五个问题的判断

1. **WB5 统一重拟合后 25 类准确率为 85.52%。** O2 的逐 task 累加结果相同。
2. **旧 ridge 统计量的时间失配非常严重。** 在相同 WB5 和测试数据上，历史 A/B 的 R0 为 33.00%，历史训练样本统一重映射后的 O1 为 85.52%，诊断 gap 为 52.52 pp。固定 WB 的 O1/O2 等价，排除了 ridge 累加实现本身的明显问题。
3. **持续写入改变了表示，但没有使旧类在 WB5 下不可解码。** O1 的旧类总体 85.00%，Task1–4 均至少 81.60%，且与冻结 WB1 的累计准确率仅差 0.40 pp。这里的结论是“在完整历史数据 oracle 重拟合下仍可解码”，不是“W_B 完全没有几何漂移”，也不是合法 no-replay 性能。
4. **WB1 未见 Task2–5 仍有高 5-way，是因为原始 sparse codes 本身已有类别结构，而固定的 4096 维二值映射足以保留可线性读取的区分信息。** 三个密度匹配随机映射和三个严格保度随机映射都产生 94.2%–95.6% 的 Task5 当前任务 5-way，与 trained WB1 的 95.6% 接近。这支持“固定高维映射”解释，而非必须依赖后续 BTSP 写入。
5. **Trained WB1 有小幅、但非压倒性的优势。** Task5 累计比密度匹配均值高 1.36 pp、比保度均值高 0.68 pp。仅三个预设种子、一个 class order 和五个 task，不足以断言这点差异稳定显著，亦不能断言 Task1 BTSP 写入完全无用。

### 范围与局限

- O1/O2 使用截至当前任务的全部历史训练数据，是 **oracle/replay diagnostic**，不是论文的 exemplar-free 算法。`TEMPORAL_MISMATCH_GAP` 和 `MEMORY_GEOMETRY_GAP` 是按用户给定端点定义的性能差，不是路径特异性的因果贡献率。
- Bernoulli 对照只在概率参数上匹配全局密度，实际边数有随机波动；严格保度对照才逐行、逐列精确匹配。双边交换确实保持度序列，但本轮没有证明 5×边数交换后已达到均匀随机的平稳分布。
- 对照只覆盖前三个预设随机种子各组与前 25 类；未做统计显著性检验、完整 20-task 运行、tau 实验或任何参数搜索。
- `same_cos`、`diff_cos` 和 `margin` 使用每个 task 当前 500 个测试样本的无序类别对均值；`seen_*` 几何使用 Task5 全部 2500 个已见测试样本。所有准确率都以原始数值（0–1）写入 CSV，表中转换成百分数。

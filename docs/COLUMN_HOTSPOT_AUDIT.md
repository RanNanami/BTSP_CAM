# W_B column hotspot 来源审计（Task1–5）

本文件是诊断结果，不改变模型、配置或训练参数。分析对象为 seed=1993 的现有训练特征缓存、原 sparse encoder，以及 Task1–5 原始 W_B 检查点。这里不讨论 CA1 或准确率调参。

## 方法与可复核性

- 使用每 task 2,500 个原训练缓存特征，按原 `RandomSparseEncoder` 编码。每样本恰有 41 个 active bits；每 task 总激活数均为 102,500。
- 按原训练顺序、eligibility 更新、plateau 抽样和 `BinaryMemory.update` 重放写入；每 task 的完整 W_B 与诊断检查点及正式训练检查点逐位相同。逐 task gross 0→1 / 1→0 总数也与已有 `btsp_learning_dynamics.csv` 一致。重放只用于审计，没有替换正式模型或重新训练。
- `sparse_bit_frequency.csv` 的 `frequency` 是某 bit 在该 task 的 2,500 个样本中激活的次数；`mean_per_sample = frequency / 2500`，是该 bit 的样本激活比例。每个 task 均列出全部 8,192 bits，包括零频 bit。
- `wb_column_evolution.csv` 的占用率是该列 4,096 行中值为 1 的比例；分位数在 8,192 列之间计算。
- `column_flip_balance.csv` 逐 task、逐列记录所有采样到的 gross 翻转（包含同一 synapse 反复翻转），`net_change = gross_01 - gross_10`。附加的 `plateau_active_exposures` 是“该 bit active 且该行发生 plateau”的写入机会数，`occupancy_before/after` 是 task 边界占用率。

## 1. 输入 sparse bit 使用高度不均

若 8,192 bits 均匀使用，每 bit 每 task 期望出现约 `102500 / 8192 = 12.51` 次；实际分布远比这集中：

| Task | 每列频次中位数 | p99 | 最大频次 | 从未激活的 bit |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 1 | 188 | 748 | 3,410 |
| 2 | 1 | 171 | 737 | 3,071 |
| 3 | 2 | 175.09 | 847 | 2,929 |
| 4 | 2 | 170.09 | 571 | 3,038 |
| 5 | 2 | 173.09 | 699 | 3,060 |

五个 task 合计时，频次中位数为 10，最大为 3,367/12,500 个样本；使用最频繁的 1% bits 承担 19.75% 的全部 active-bit 事件。Task5 占用率最高的 82 列，与累计输入频次最高的 82 bits 有 75 列重合；这 82 个热点列承受 19.65% 的输入激活。

**判断 A（输入 sparse 编码偏置）：强证据支持。** 这里的“偏置”是实测 bit 使用频率不均，不等于已证明偏置一定来自 Gaussian projection、bias、ViT 特征分布中的某一个单独因素。本轮没有改变或拆解编码器。

## 2. 列占用率随写入机会累积

| Task | 全局/平均列占用率 | 列中位数 | p90 | p99 | 最大列 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 0.916% | 0.073% | 2.295% | 13.967% | 36.694% |
| 2 | 1.658% | 0.220% | 4.392% | 20.725% | 46.338% |
| 3 | 2.347% | 0.391% | 6.592% | 27.066% | 48.706% |
| 4 | 2.994% | 0.562% | 8.689% | 31.787% | 49.536% |
| 5 | 3.592% | 0.732% | 10.718% | 35.722% | 49.756% |

累计输入频次与 Task5 列占用率的 Pearson 相关为 **0.921**，Spearman 为 **0.994**；累计 plateau-active 写入机会与占用率的 Pearson 相关为 **0.919**。最热 82 列每列平均累计被输入选中 1,228 次、获得 7,898 次写入机会；其他列分别约 50.8 次、318 次（均约 24–25 倍差距）。对应的最终平均占用率是 40.95% 对 3.21%。Task5 所有占用率 ≥40% 的 42 列均位于这 82 列内。

**判断 B（XOR 写入累积）：支持，作为把高频输入转成热点占用的机制。** 当前写入只触及 active sparse bits 和采样到 plateau 的行，且每次以固定概率 XOR 翻转。由全零开始，翻转概率为 0.5 时，一个 synapse 首次获得写入机会后，其期望状态就为 0.5；高频列的关键效应是让**更多行**获得至少一次机会，而非让已触及行单向加 1。后续写入仍会双向翻转。“累积”指写入机会覆盖范围和当前状态分布的累积；Task5 最大列 49.756% 与这种机制相符，但不是对其他模型的反事实证明。全局平均仍只有 3.592%，因此是**局部列热点**，不是整个 W_B 饱和。

## 3. 1→0 翻转是否不足

| Task | 全列 gross 0→1 | 全列 gross 1→0 | 期末净增加 |
| ---: | ---: | ---: | ---: |
| 1 | 325,398 | 18,130 | 307,268 |
| 2 | 279,988 | 30,781 | 249,207 |
| 3 | 272,846 | 41,732 | 231,114 |
| 4 | 267,950 | 50,872 | 217,078 |
| 5 | 262,229 | 61,511 | 200,718 |

占用率最高的 82 列累计有 230,589 次 0→1、93,037 次 1→0；它们只占全部列 1%，却承担 **45.83% 的全部 1→0**。这些列的累计 1→0 / 0→1 比例为 **0.403**，其余列为 **0.093**。仅 Task5，在同一组热点列上 0→1 为 40,354、1→0 为 27,619，比值已到 **0.684**。按写入机会计，热点列 0→1 与 1→0 分别为 0.356 与 0.144，合计约 0.5，与既有 XOR flip probability 一致；其余列对应 0.457 与 0.043，也合计约 0.5。

**判断 C（LTD 不足）：没有直接证据支持“1→0 未发生或异常受抑”。** 当前实现的 1→0 是 XOR 对已为 1 的权重执行翻转，并非独立采样的 LTD 分支。热点列的 1→0 相当活跃、且随占用增长而增加；总量仍小于 0→1，主要与全零起点、大量低占用列和逐步填充一致。是否需要不同的 LTD 规则或强度是另一项反事实问题，本轮不能据此断言，也未做任何参数选择。

## 结论与边界

证据链为：**sparse bit 使用高度集中 → 对应列获得多得多的 plateau 写入机会 → XOR 反复翻转使这些列局部趋近 50% 占用**。A 解释“哪些列变热”，B 解释“为什么它们逐渐变热”；C 不是当前观测中的主要异常。相关性与逐位回放支持这一归因，但不能单凭本轮数据把编码偏置进一步归结于随机投影的某一项，也不能证明去掉某机制后的因果效果。

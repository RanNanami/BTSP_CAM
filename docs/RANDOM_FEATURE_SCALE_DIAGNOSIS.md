# Random feature scale 只读诊断（Task1–5）

本报告只重算已有 12,500 个 frozen ViT 训练特征在**同一组** `R,b` 和 exact `k=41` 下的 sparse code。没有修改正式 encoder、配置、W_B 或训练流程；没有用准确率筛选归一化。论文证据另见 [来源审计](RANDOM_FEATURE_SCALE_AUDIT.md)。原始和 global-center-oracle 的逐 bit 频次均与上一轮独立诊断完全一致。

## 编码反事实

“top 1%”指 8,192 bits 中频次最高的 82 bits 占全部 `12,500×41=512,500` 次 winner 事件的份额。频次熵为 `−∑_i p_i log p_i / log 8192`，CV 为逐 bit winner 次数的总体标准差/均值。下表的 cosine 是每类 500 个训练样本、25 类上**不同样本配对**的精确期望；同类和类对等权。winner agreement 是相对原始编码平均每样本 41 个 winner 的交集比例。

| 离线变体 | top-1% 份额 | 从未胜出 bits | 频次 CV | 熵 | 同类 cosine | 异类 cosine | margin | 与 raw winner 一致 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| raw `h`，`Rh+b` | 19.75% | 1,227 | 2.659 | 0.846 | 0.08199 | 0.03859 | 0.04339 | 100% |
| L2 `h/‖h‖₂`，含 `b` | **46.60%** | **5,256** | 5.766 | 0.688 | 0.23255 | 0.16877 | 0.06379 | 23.90% |
| 逐样本维度中心化 `h−mean_dim(h)`，含 `b` | 19.82% | 1,217 | 2.654 | 0.846 | 0.08187 | 0.03844 | 0.04343 | 96.34% |
| 全局向量中心化 `h−mean_train(h)`，含 `b` | **4.87%** | **0** | 0.762 | 0.974 | 0.03083 | 0.00687 | 0.02396 | 37.95% |
| L2 `h/‖h‖₂`，不加 `b` | 19.79% | 1,224 | 2.668 | 0.846 | 0.08230 | 0.03883 | 0.04347 | 97.35% |
| raw `Rh/√768+b` | 29.88% | 3,033 | 3.809 | 0.778 | 0.12952 | 0.07540 | 0.05412 | 46.65% |
| raw `Rh/√8192+b` | 70.81% | 6,811 | 8.470 | 0.586 | 0.42042 | 0.36170 | 0.05872 | 10.11% |

**观察：** L2 normalization 并未缓解 winner monopoly，在保留固定 `b` 时明显加剧。逐样本减去自己的 768-D **标量均值**几乎不改变编码；它没有减去跨样本的 768-D **向量均值**。全局向量中心化显著缓解集中，但该均值使用了 Task1–5（包含未来任务）的全部训练特征，是 **oracle diagnostic only**，不符合本项目的 streaming/no-replay 约束，绝不视作可部署预处理。

L2 不加 `b` 的结果与上一轮 raw 不加 `b` 完全一致，这不是巧合：对每个样本，`‖h‖₂>0` 是作用于所有投影 bit 的同一个正标量，所以 `Top-k(Rh/‖h‖₂)=Top-k(Rh)`。L2 加 `b` 改变了 **bias/投影** 的相对尺度，才使 winner 大幅换位。相同原因，单独对 `Rh` 做 `1/√d` 或 `1/√m` 缩放而不同时缩放 `b`，也不能假定会减轻集中；本轮两种尺度都使固定 `b` 更具支配性，winner monopoly 更严重。若 `R` 与 `b` 同乘一个正数，top-k 排名则严格不变。

绝对 margin **不是**本轮的选择目标。L2 与强投影缩放虽然出现较大的“同类减异类”数值，也同时显著抬高异类共享 cosine；这不是准确率或 CIL 适用性的证明。

## `Rh` 与 `b` 的尺度

下表统计**不加 `b` 的 `Rh`**。`Rh global std` 是所有样本×bit 分数的总体标准差；`bit-mean std` 是先逐 bit 对样本求均值，再跨 bit 求标准差；`sample std median` 是逐 bit 在样本间求标准差后的中位数。`b` 跨 bit 标准差恒为 1.009。

| 变体 | 输入范数中位数 | `Rh` global std | bit-mean std | sample std median | `std(Rh)/std(b)` |
| --- | ---: | ---: | ---: | ---: | ---: |
| raw | 47.78 | 50.78 | 27.35 | 42.08 | **50.34** |
| L2 | 1.00 | 0.995 | 0.547 | 0.822 | **0.986** |
| 逐样本维度中心化 | 47.76 | 50.75 | 27.29 | 42.08 | **50.30** |
| 全局向量中心化（oracle） | 40.04 | 42.79 | ≈0 | 42.08 | **42.41** |
| raw `Rh/√768` | 47.78 | 1.833 | 0.987 | 1.519 | **1.816** |
| raw `Rh/√8192` | 47.78 | 0.561 | 0.302 | 0.465 | **0.556** |

raw `‖h‖₂` 的 p10/中位数/p90 为 **41.32 / 47.78 / 62.24**，RMS 为 **51.04**。raw `Rh` 的跨样本×bit 标准差 **50.78**，与这个范数尺度相符；固定 `b` 的标准差 **1.009**，相对 raw `Rh` 几乎可忽略（虽仍能改变靠近 top-k 边界的少数 winner）。L2 后两者成为近同尺度，这是**数学事实**，不是论文采用 L2 的证据。逐样本维度均值的绝对值平均仅 **0.0485**；它对应的全局均值向量在全 1 方向上的投影范数约 **1.34**，而全局特征均值范数为 **27.76**，解释了这种中心化为什么不能消除主要固定偏移。

## 理论 sanity check 与 Appendix C

令每一行 `R_i∼N(0,I_d)`，对**固定** `h`：

`R_i h = ∑_{j=1}^d R_{ij}h_j ∼ N(0,∑_j h_j²)=N(0,‖h‖₂²).`

若 `b_i∼N(0,1)` 且独立，则对一个固定输入，随机抽取的 `R_i h` 与 `b_i` 的标准差之比是 `‖h‖₂:1`。raw 样本典型范数约 48，使 `Rh` 支配；L2 后范数为 1，二者同尺度。这里的概率是**对随机抽取投影行**而言，不等于冻结一次 `R,b` 后跨真实样本的 winner 频率必然均匀。

将输入写作 `h=μ+δ`，同一固定行的分数为 `R_i h=R_i μ+R_i δ`。`R_i μ` 对所有样本都是该 bit 的持久偏移；跨 bit 的观测标准差为 **27.35**，远大于 `b` 的 **1.009**。exact top-k 反复选择这些具有较高固定偏移的 bit，产生 persistent winner bias。oracle 减 `μ` 令训练集上的逐 bit `Rh` 均值近零，top-1% 份额随之下降。逐样本减一个标量没有消去大部分 `μ`。

**论文事实：** Eq.(3)/(10) 规定 `R,b∼N(0,1)`，未规定 `h` L2、center、bounded norm 或投影缩放。Appendix B.1/C.2 为碰撞推导**直接建模**编码后无关样本的支持集是独立、均匀 `k`-subsets，未从固定 `R,b` 加真实 frozen ViT `h` 推出该模型。它不是隐含的 unit-norm 或 centered-feature 前提。当前高度不均的 winner 频次与“均匀支持集”近似相距甚远，因此该局部碰撞结论不能不经检验就套到这批 raw ViT codes。

**PILOT 行为：** 非 CODA 的 CIFAR224 图像变换只有 crop/flip/resize 与 ToTensor；frozen timm ViT 输出后没有显式 L2 或全局中心化。当前 timm 对应模型内部有最终 LayerNorm、`head=Identity`，但 LayerNorm 不保证输出 `‖h‖₂=1` 或跨样本 `μ=0`。

## 最终判断

1. **论文明确 feature normalization？** 没有（NOT_FOUND）；PILOT 路径也没有输出 L2。
2. **Eq.(3)/Appendix C 隐含 unit-norm 或 centered 假设？** 没有。明确的是编码后**独立、均匀支持集**的建模假设，而这没有被 Eq.(3) 对任意真实 `h` 证明。
3. **raw ViT feature 与 `R,b` 尺度失配？** 在本实现中是：`std(Rh)/std(b)=50.34`。这符合论文按元素标准正态 `R,b` 与 raw `‖h‖≈48` 的直接数学后果，不能单凭它称为代码公式错误。
4. **L2 缓解？** 否。固定 `b` 变得可比后，top-1% 份额升至 46.60%，零胜出 bit 升至 5,256；无 `b` 的 L2 与 raw 无 `b` 排名等价。
5. **逐样本维度中心化缓解？** 基本没有，19.75%→19.82%。
6. **global-center oracle 缓解？** 显著，19.75%→4.87%、零胜出 1,227→0；但该离线操作包含未来任务信息，不是合法 CIL 实现。
7. **hotspot 最可能归类？** 现有代码与 Eq.(3) 和 PILOT 输出路径一致，故没有本轮可证的“实现错误”。作者是否另用了未公开预处理 **NOT_FOUND / 无证据**，不能断言。证据最直接支持：**论文公式作用在当前 raw ViT 特征上自然产生的统计现象**，其固定偏移还使 Appendix C 的均匀支持集近似在本设置下失准。
